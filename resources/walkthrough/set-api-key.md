DeepSeek for Copilot Chat uses your own DeepSeek API key to make Flash and V4 Pro available in the model picker.

Paste it once, then update or remove it later from the Command Palette.

- `Cmd/Ctrl + Shift + P`: Open the Command Palette
- `DeepSeek Cache-Aware: Set API Key`: Set or update your API key
- `DeepSeek Cache-Aware: Clear API Key`: Remove your API key
- `DeepSeek Cache-Aware: Get API Key`: Create a DeepSeek API key
